# 列表操作

> 列表域相关操作。

#### 本域工具

| 工具 | 功能简述 | 详情 |
|------|----------|------|
| `wps.lists.apply_with_level` | 批量按级别为多个段落应用列表模板 | [详情](lists-apply.md#apply-with-level) |
| `wps.lists.blocks` | 枚举文档内列表块 | [详情](lists-blocks.md#blocks) |
| `wps.lists.custom_bullet` | 设置自定义项目符号 | [详情](lists-custom.md#custom-bullet) |
| `wps.lists.data` | 在线文字文档段落或范围列表属性：支持 查询/设置 | [详情](lists.data.md) |
| `wps.lists.level_style` | 按级别定向设置列表编号样式 | [详情](lists-level.md#level-style) |
| `wps.lists.multilevel` | 对字符区间应用大纲多级列表模板 | [详情](lists-multilevel.md#multilevel) |
| `wps.lists.number_format` | 为段落设置自定义编号格式 | [详情](lists-number.md#number-format) |
| `wps.lists.remove` | 移除列表格式 | [详情](lists-remove.md#remove) |
| `wps.lists.restart` | 段落列表重新编号 | [详情](lists-restart.md#restart) |
