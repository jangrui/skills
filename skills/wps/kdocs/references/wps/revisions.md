# 修订操作

> 修订域相关操作。

#### 本域工具

| 工具 | 功能简述 | 详情 |
|------|----------|------|
| `wps.revisions.accept` | 接受指定修订 | [详情](revisions-accept.md#accept) |
| `wps.revisions.accept_all` | 在线文字文档接受全部修订：支持 查询/设置 | [详情](revisions.accept_all.md) |
| `wps.revisions.accept_by_author` | 在线文字文档按作者接受修订：支持 查询/设置 | [详情](revisions.accept_by_author.md) |
| `wps.revisions.all` | 查询全部修订 | [详情](revisions-all.md#all) |
| `wps.revisions.by_author` | 按作者查询修订 | [详情](revisions-by.md#by-author) |
| `wps.revisions.reject` | 拒绝指定修订 | [详情](revisions-reject.md#reject) |
| `wps.revisions.reject_all` | 在线文字文档拒绝全部修订：支持 查询/设置 | [详情](revisions.reject_all.md) |
| `wps.revisions.reject_by_author` | 在线文字文档按作者拒绝修订：支持 查询/设置 | [详情](revisions.reject_by_author.md) |
| `wps.revisions.status` | 设置在线文字文档的修订模式状态 | [详情](revisions.status.md) |
