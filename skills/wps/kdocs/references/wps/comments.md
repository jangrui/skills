# 批注操作

> 批注域相关操作。

#### 本域工具

| 工具 | 功能简述 | 详情 |
|------|----------|------|
| `wps.comments.add` | 在在线文字文档中插入批注 | [详情](comments-add.md#add) |
| `wps.comments.author` | 按作者查询批注 | [详情](comments-author.md#author) |
| `wps.comments.count` | 查询批注数量 | [详情](comments-count.md#count) |
| `wps.comments.data` | 查询批注数据 | [详情](comments-data.md#data) |
| `wps.comments.delete` | 删除在线文字文档指定批注 | [详情](comments-delete.md#delete) |
| `wps.comments.delete_all` | 删除在线文字文档全部批注 | [详情](comments-delete.md#delete-all) |
| `wps.comments.list` | 查询批注列表 | [详情](comments-list.md#list) |
| `wps.comments.modify_text` | 修改在线文字文档批注文本 | [详情](comments-modify.md#modify-text) |
| `wps.comments.paragraph_insert` | 在在线文字文档指定段落插入批注 | [详情](comments-paragraph.md#paragraph-insert) |
| `wps.comments.range_insert` | 在在线文字文档字符区间插入批注 | [详情](comments-range.md#range-insert) |
| `wps.comments.reply` | 回复在线文字文档批注 | [详情](comments-reply.md#reply) |
| `wps.comments.resolve` | 解决在线文字文档批注 | [详情](comments-resolve.md#resolve) |
| `wps.comments.set_done` | 设置在线文字文档批注完成状态 | [详情](comments-set.md#set-done) |
