# 图片操作

> 图片域相关操作。

#### 本域工具

| 工具 | 功能简述 | 详情 |
|------|----------|------|
| `wps.images.all` | 删除全部图片 | [详情](images-all.md#all) |
| `wps.images.alternative_text` | 图片替代文字 | [详情](images.alternative_text.md) |
| `wps.images.border` | 设置图片的边框 | [详情](images-border.md#border) |
| `wps.images.count` | 查询图片数量 | [详情](images-count.md#count) |
| `wps.images.crop` | 设置图片的裁剪 | [详情](images-crop.md#crop) |
| `wps.images.crop_to_shape` | 设置图片的按形状裁剪 | [详情](images-crop.md#crop-to-shape) |
| `wps.images.data` | 删除图片数据 | [详情](images-data.md#data) |
| `wps.images.info` | 查询图片信息 | [详情](images-info.md#info) |
| `wps.images.insert` | 在文档、段落或区间插入图片（file_path 为图片 URL） | [详情](images.insert.md) |
| `wps.images.list` | 查询图片列表 | [详情](images-list.md#list) |
| `wps.images.locate_paragraph` | 查询图片所在段落 | [详情](images-locate.md#locate-paragraph) |
| `wps.images.lock_aspect_ratio` | 锁定图片纵横比 | [详情](images-lock.md#lock-aspect-ratio) |
| `wps.images.move_to_paragraph` | 将图片移动到段落 | [详情](images-move.md#move-to-paragraph) |
| `wps.images.resize` | 设置图片尺寸 | [详情](images-resize.md#resize) |
| `wps.images.scale` | 图片缩放百分比 | [详情](images-scale.md#scale) |
| `wps.images.title` | 设置图片标题 | [详情](images-title.md#title) |
| `wps.images.wrap` | 设置图片的环绕方式 | [详情](images-wrap.md#wrap) |
