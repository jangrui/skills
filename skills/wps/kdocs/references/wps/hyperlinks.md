# 超链接操作

> 超链接域相关操作。

#### 本域工具

| 工具 | 功能简述 | 详情 |
|------|----------|------|
| `wps.hyperlinks.address` | 更新超链接地址 | [详情](hyperlinks-address.md#address) |
| `wps.hyperlinks.all` | 删除全部超链接 | [详情](hyperlinks-all.md#all) |
| `wps.hyperlinks.count` | 查询超链接数量 | [详情](hyperlinks-count.md#count) |
| `wps.hyperlinks.data` | 在线文字文档超链接数据：支持删除/查询 | [详情](hyperlinks.data.md) |
| `wps.hyperlinks.insert` | 在段落或区间插入超链接 | [详情](hyperlinks.insert.md) |
| `wps.hyperlinks.list` | 查询超链接列表 | [详情](hyperlinks-list.md#list) |
