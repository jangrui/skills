# 文字文档文本操作

| 工具 | 功能简述 | 详情 |
|------|----------|------|
| `wps.texts.alignment` | 设置在线文字文档文本的段落对齐 | [详情](texts.alignment.md) |

| `wps.texts.char_border` | 设置文本的字符边框 | [详情](texts-char.md#char-border) |
| `wps.texts.char_case` | 设置文本的更改大小写 | [详情](texts-char.md#char-case) |
| `wps.texts.char_spacing` | 设置文本的字符间距与缩放 | [详情](texts-char.md#char-spacing) |
| `wps.texts.clear_format` | 设置在线文字文档文本的清除段落格式 | [详情](texts.clear_format.md) |
| `wps.texts.content` | 在线文字文档文本内容：支持查询/插入/设置/删除 | [详情](texts.content.md) |
| `wps.texts.count` | 查询段落数量 | [详情](texts-count.md#count) |

| `wps.texts.emphasis_mark` | 在线文字文档文本的着重符号：支持 设置/查询 | [详情](texts.emphasis_mark.md) |
| `wps.texts.enclosed_char` | 设置文本的带圈字符 | [详情](texts-enclosed.md#enclosed-char) |

| `wps.texts.font_batch` | 设置在线文字文档文本的批量修改段落字体 | [详情](texts.font_batch.md) |
| `wps.texts.font_color` | 设置在线文字文档文本的段落字体颜色 | [详情](texts.font_color.md) |
| `wps.texts.font_gradient` | 按字符区间设置文字双色渐变填充 | [详情](texts-font.md#font-gradient) |

| `wps.texts.format_copy` | 将源段落格式复制到目标段落范围（格式刷） | [详情](texts-format.md#format-copy) |
| `wps.texts.heading` | 在线文字文档文本的标题段落：支持插入/设置 | [详情](texts.heading.md) |
| `wps.texts.highlight` | 设置在线文字文档文本的段落高亮 | [详情](texts.highlight.md) |
| `wps.texts.indent` | 设置在线文字文档文本的段落缩进 | [详情](texts.indent.md) |

| `wps.texts.replace` | 在在线文字文档中查找并替换文本 | [详情](texts.replace.md) |
| `wps.texts.search` | 搜索文本 | [详情](texts-search.md#search) |
| `wps.texts.shading` | 在线文字文档文本的段落底纹：支持 插入/设置/查询 | [详情](texts.shading.md) |

| `wps.texts.two_lines_in_one` | 设置文本的双行合一 | [详情](texts-two.md#two-lines-in-one) |
| `wps.texts.underline_color` | 在线文字文档文本的下划线颜色：支持 设置/查询 | [详情](texts.underline_color.md) |
| `wps.texts.word_count` | 查询文本的字数统计 | [详情](texts-word.md#word-count) |
