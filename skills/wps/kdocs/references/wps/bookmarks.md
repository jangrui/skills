# 书签操作

> 书签域相关操作。

#### 本域工具

| 工具 | 功能简述 | 详情 |
|------|----------|------|
| `wps.bookmarks.content` | 在线文字文档书签内容：支持查询/设置 | [详情](bookmarks.content.md) |
| `wps.bookmarks.count` | 查询书签的数量 | [详情](bookmarks-count.md#count) |
| `wps.bookmarks.delete` | 删除书签 | [详情](bookmarks-delete.md#delete) |
| `wps.bookmarks.exists` | 查询书签的是否存在 | [详情](bookmarks-exists.md#exists) |
| `wps.bookmarks.goto` | 跳转到书签 | [详情](bookmarks-goto.md#goto) |
| `wps.bookmarks.insert` | 在段落或区间插入书签 | [详情](bookmarks.insert.md) |
| `wps.bookmarks.list` | 查询书签的列表 | [详情](bookmarks-list.md#list) |
| `wps.bookmarks.rename` | 重命名书签 | [详情](bookmarks-rename.md#rename) |
